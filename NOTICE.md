The stationary-machine-gun component contains a separately named derivative
of Anomaly 1.5.3's `wpn_mounted_pkm_trenoga.ogf` game asset.
The game geometry/UVs are not original Hardcoon artwork. Preparation
adds a missing physical pitch-bone shape, remaps a missing texture to
an installed stock texture and routes userdata to a private configuration.
The speed variants reuse the same geometry and physics verbatim,
changing only native rotation-speed values in private model userdata.

code, models, textures or sounds are included. Original game-derived content

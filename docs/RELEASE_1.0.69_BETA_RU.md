# Anomaly Donation Bridge 1.0.69 Beta

Добавлено:

- в **Настройки → Общие настройки** появился чекбокс **«Выводить в лог игры»**;
- по умолчанию он включён и игра показывает технические строки `Имя донатчика — Название пресета`;
- при выключенном чекбоксе пресеты, очередь, автосохранения и журнал в самой программе продолжают работать;
- настройка сохраняется и передаётся в игру отдельно для каждой цепочки эффектов.

Версия аддона повышена до 1.0.40. После обновления программы нажмите
**«Установить / обновить аддон и эффекты»** и полностью перезапустите игру.

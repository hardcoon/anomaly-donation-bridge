# Чат зрителей

[← Первый запуск](../README.md) · [Голосования](USAGE_RU.md#голоса-из-чата-зрителей)

Раздел **«Чат зрителей»** в левой панели объединяет YouTube, Twitch и
VK Видео Live в одну ленту. Рядом с сообщением показан значок площадки,
ник выделен цветом. Цвет одного автора сохраняется в пределах выбранной темы.

## Подключение

Раскройте блок **«Подключения»**, укажите адрес и нажмите **«Подключить»**
в строке нужной площадки. Весь блок можно свернуть, оставив больше места чату.

| Площадка | Что указать |
| --- | --- |
| YouTube | Конкретный текущий эфир: `youtube.com/watch?v=…`, `youtube.com/live/…`, `youtu.be/…` или ID видео. |
| Twitch | Имя канала или `https://twitch.tv/канал`. |
| VK Видео Live | Имя канала или `https://live.vkvideo.ru/канал`; прежние адреса `vkplay.live` также распознаются. |

Публичные чаты читаются анонимно: вход в аккаунт и свой API-ключ не нужны.
Сообщения отправлять из ADB нельзя. Ссылка на запись VK определяет канал;
чат записи не воспроизводится. Обычный чат сообщества ВКонтакте этим разделом
не подключается.

Ссылки и включённые подключения сохраняются; при запуске программы приём
восстанавливается. Кнопка **«Отключить»** останавливает выбранный источник.
Статус каждой площадки отображается под её полем. При сетевых ошибках
соединение повторяется с паузой.

YouTube в этом разделе использует гостевой веб-чат. В **Настройки →
Интеграция → YouTube API** сохранён [резервный способ](YOUTUBE_CHAT_SETUP_RU.md)
через официальный API и свой ключ. Он необязателен. Переключение способа
не удаляет сохранённый ключ; два подключения к YouTube одновременно не создаются.

## Голосования и очередь

В настройках голосования отметьте **«Чат зрителей»**: команды всех трёх
площадок поступают в одно голосование. Один аккаунт на каждой площадке даёт
один голос за раунд. Недавняя история при подключении и повторная доставка
сообщений новых голосов не добавляют.

Обычное сообщение само по себе эффект не запускает. После розыгрыша победитель
поступает в общую очередь ADB. Её полоса состояния видна над чатом.

## Прокрутка и отдельное окно

В памяти ленты хранятся последние **1500 сообщений**. При открытии видны
последние **150**, более ранние сообщения подгружаются порциями при прокрутке
вверх. Счётчик «получено» накопительный.

В меню с шестерёнкой над лентой можно включить **«Отображать временные метки»**.

Колёсико вверх сразу приостанавливает автопрокрутку. Чтобы вернуться к новым
сообщениям, прокрутите вниз в нижние **15%** списка либо нажмите кнопку новых
сообщений. **«Очистить»** очищает ленту; голоса и очередь эффектов не сбрасываются.

Через **ПКМ по «Чат зрителей» → «Открыть в новом окне»** можно вынести чат
из главного окна. Подключения и лента остаются общими. [Отдельные окна](DETACHED_WINDOWS_RU.md).

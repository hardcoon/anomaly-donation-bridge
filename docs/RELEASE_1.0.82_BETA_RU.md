# Anomaly Donation Bridge 1.0.82 Beta

## Мутант-напарник

- Добавлен шаблон **«Заспавнить мутанта-напарника»**.
- В настройках можно отметить несколько допустимых секций из живого каталога
  мутантов и включить случайный выбор одной из них.
- Создаётся один настоящий мутант через `alife_create`, без симуляционного
  отряда и без подмены обычного NPC моделью мутанта.
- Мутант получает имя донатчика, следует за игроком примерно до дистанции
  пяти метров и помогает атаковать противников игрока.
- При наведении штатная полоска здоровья показывает строку
  `Имя донатчика: N% HP`.
- Состояние напарника хранится в сохранении игры, а тот же одиночный объект
  переносится вслед за игроком между локациями.
- Собственная регенерация выбранного мутанта не меняется.

Игровой аддон обновлён до версии **1.0.46**. После распаковки новой версии
нажмите **«Установить / обновить аддон и эффекты»** и полностью перезапустите
игру. Автоматические тесты проверяют прямой спавн, следование, передачу цели,
сохранение имени и перенос между уровнями; окончательное поведение конкретных
мутантов зависит от их штатного ИИ и проверяется в игре.

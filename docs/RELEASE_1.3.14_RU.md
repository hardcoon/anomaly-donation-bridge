# Anomaly Donation Bridge 1.3.14

Добавлены два шаблона.

- **БТР-напарник (экспериментально)** следует за игроком и прикрывает его огнём. Правым Ctrl можно указать точку под прицелом. Можно и самому сесть за руль — башня продолжит стрелять по врагам.
- **Странствующий торговец** появляется с именем донатера и продаёт случайные товары из восьми настраиваемых категорий. По умолчанию он остаётся на 180 секунд и даёт скидку 80%. Метка в КПК показывает, сколько времени осталось. Ассортимент сохраняется вместе с игрой.

После обновления установите аддон **1.0.168** и эффекты через настройки программы, полностью перезапустите игру и обновите каталог.

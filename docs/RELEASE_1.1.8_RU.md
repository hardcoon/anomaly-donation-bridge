# Anomaly Donation Bridge 1.1.8

Добавлен шаблон «Собрать лут и убрать трупы»: удаляет трупы в заданном радиусе
и переносит их лут в один рюкзак у ног героя. Может помочь с вылетами,
если рядом много трупов.

- Радиус удаления настраивается; по умолчанию — 100 м.
- Удаление трупов мутантов включается отдельным чекбоксом. Разделка не выполняется:
  уже имеющиеся предметы переносятся, неполученные части пропадут.
- Сюжетные, квестовые и защищённые тела пропускаются.

После обновления нажмите «Установить / обновить аддон и эффекты» при закрытой
игре, затем запустите её заново. Основной аддон — 1.0.69; всего 48 файловых шаблонов.

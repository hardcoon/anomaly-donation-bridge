# Anomaly Donation Bridge 1.0.59 Beta

Версия 1.0.59 Beta переводит программу, игровой аддон, скрипты эффектов и
поставку на Hardcoon No-Resale License 1.0.

- Программу можно бесплатно использовать, изменять и бесплатно распространять.
- Разрешено использовать программу для монетизируемых стримов и видео.
- Запрещены перепродажа, платная раздача и включение программы в платный сервис
  без отдельного письменного разрешения Hardcoon.
- В переносимый ZIP добавлен `LICENSE.txt` с полными условиями.

Игровая логика и аддон в этом выпуске не изменялись. Версия аддона остаётся
1.0.30; достаточно заменить программу и сохранить установленный аддон.

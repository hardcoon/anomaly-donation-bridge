# Anomaly Donation Bridge 1.0.79 Beta

Исправлено подключение DonateX по внешнему API-ключу:

- ключ из кабинета DonateX теперь проверяется всеми документированными
  способами авторизации: `token`, `access_token` и `Authorization: Bearer`;
- при вставке удаляются переносы строк и невидимые символы буфера обмена,
  способные вызвать ложный ответ `401 Unauthorized`;
- при окончательном отказе DonateX показывается понятное сообщение о повторном
  копировании или перевыпуске ключа;
- из инструкции подключения убрано упоминание DonationAlerts: DonateX остаётся
  отдельной независимой интеграцией, передающей события в общую очередь
  приложения;
- добавлены автоматические проверки переключения способов авторизации после
  ответа `401`.

Игровой аддон не менялся и остаётся версии 1.0.44 — переустанавливать его не
требуется.

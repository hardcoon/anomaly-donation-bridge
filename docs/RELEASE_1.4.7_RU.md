# Anomaly Donation Bridge 1.4.7

- Новый шаблон **«Дать пинка»**: автоматический подброс на высоту **2–500 м**, по умолчанию **5 м**. Скорость рассчитывается по текущей гравитации. На Monolith используется штатное управление скоростью, на старом движке — совместимый путь через обычный прыжок. Потолки и другие препятствия ограничивают подъём.
- Новый шаблон **«Дождь из предметов»**: мультивыбор подвижных пропов из установленной игры и модов, случайный выбор из отмеченных, количество, шаг сетки и высота. Начальные значения — **9 объектов, 3 м, 15 м**. Объекты создаются порциями по два за кадр.
- Сканер получает физические объекты через объединённые INI и виртуальную файловую систему игры, включая MO2. Объекты с квестовыми привязками, закреплёнными костями, специальной логикой или отсутствующей моделью недоступны для дождя.
- Оба эффекта сохраняют запрос до выполнения: загрузка **ADB after** повторяет подброс или дождь. Более позднее сохранение после выполнения подброса его не повторяет; сохранение во время дождя продолжает оставшуюся часть без повторного создания уже выполненных строк плана.

Бочки используют штатную физику и разрушение. Взрыв при падении зависит от урона при столкновении и настроек конкретной бочки; принудительный подрыв не добавлен.

Для обновления с **1.4.6** закройте ADB через трей и запустите EXE из нового комплекта. В программе обновите аддон до **1.0.184**, установите новый комплект из **72 шаблонов** и полностью перезапустите игру. После загрузки обновите каталог кнопкой ↻ в карточке игры.

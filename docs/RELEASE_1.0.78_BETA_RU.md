# Anomaly Donation Bridge 1.0.78 Beta

Исправлена совместимость и защита пользовательских настроек:

- добавление DonateX больше не повышает версию `settings.json`: новые поля
  являются необязательными, поэтому файл сохраняется в совместимой схеме 13;
- файл схемы 14, кратковременно создававшийся версией 1.0.77, читается без
  ошибки и при следующем сохранении возвращается к схеме 13;
- если настройки не удалось загрузить, программа при завершении больше не
  сохраняет пустой объект поверх существующего файла;
- перед каждой заменой `settings.json` предыдущая версия атомарно сохраняется
  как `settings.json.bak`;
- добавлены автоматические проверки сохранности файла после неудачного запуска,
  обратной совместимости схемы 14 и резервного копирования.

Интеграция DonateX из 1.0.77 сохранена. Игровой аддон не менялся и остаётся
версии 1.0.44 — переустанавливать его не требуется.

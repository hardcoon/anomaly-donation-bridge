**Anomaly Donation Bridge 1.3.6**

- В настройках групп добавлена задержка между срабатываниями эффектов. По умолчанию — 1 секунда, можно изменить или поставить 0.
- Внутри группы используется её задержка вместо глобальной. Между отдельными донатами глобальная пауза сохраняется.
- Настройка сохраняется автоматически; интервал ожидающих эффектов восстанавливается вместе с очередью после перезапуска программы.

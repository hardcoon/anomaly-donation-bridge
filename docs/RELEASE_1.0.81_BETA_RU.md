# Anomaly Donation Bridge 1.0.81 Beta

## Статус интеграций

- Подключённые сервисы теперь всегда подписаны явно:
  `DonationAlerts: имя` и `DonateX: имя`.
- Если подключены оба сервиса, главная страница показывает оба имени через
  разделитель. Если подключён один — отображается только он.
- Добавлена автоматическая проверка, подтверждающая, что DonateX может один
  включить обработку донатов и не зависит от подключения DonationAlerts.

Игровой аддон не менялся и остаётся версии **1.0.45**. Для этого обновления
достаточно заменить программу и перезапустить её; переустанавливать аддон не
требуется.

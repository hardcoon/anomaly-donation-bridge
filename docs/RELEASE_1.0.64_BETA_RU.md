# Anomaly Donation Bridge 1.0.64 Beta

Исправления:

- максимальное здоровье убрано из постоянного изменения параметров: неподдерживаемое API больше не блокирует изменение прыжка, скорости и переносимого веса;
- старое поле максимального здоровья в уже сохранённых пользовательских пресетах безопасно игнорируется;
- постоянное изменение параметров сообщает о применённых значениях в КПК;
- группировка напарника назначается через безопасный игровой API и повторно синхронизируется после загрузки и переходов;
- удалено опасное присваивание строкового значения методу `community()`, вызывавшее вылет в `calculate_rankings`;
- при загрузке выполняется восстановление напарников, созданных ошибочной версией скрипта.

Версия аддона повышена до 1.0.35. После обновления программы нажмите
«Установить / обновить аддон и эффекты» и полностью перезапустите игру.

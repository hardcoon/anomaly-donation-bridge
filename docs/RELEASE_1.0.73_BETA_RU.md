# Anomaly Donation Bridge 1.0.73 Beta

Исправлено и добавлено:

- количество пачек патронов теперь действительно передаётся игровому скрипту;
  значение `N` применяется отдельно к каждой фактически выданной единице оружия;
- в пресете **«Выдать предмет»** появилась категория
  **«Случайный артефакт»**;
- случайный артефакт выбирается только среди доступных безопасных секций
  свежего каталога текущей сборки игры.

Версия аддона повышена до 1.0.43. После обновления программы нажмите
**«Установить / обновить аддон и эффекты»**, затем полностью перезапустите игру.

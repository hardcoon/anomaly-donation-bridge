# Anomaly Donation Bridge 1.0.94 Beta

## Новые шаблоны

- Добавлен экспериментальный шаблон **«Заспавнить мутанта-напарника»**. Мутант
  получает имя донатчика, следует за игроком, помогает в бою, переходит между
  локациями, отмечается на карте КПК и показывает имя с процентом здоровья при
  наведении. При гибели напарника появляется сообщение в КПК.
- Добавлен шаблон **«Донат-босс»**: враждебный NPC с именем донатчика появляется
  на текущей локации, преследует игрока и выдаёт награду после выполнения
  задания на ликвидацию. Настраиваются здоровье, награда и дальность появления.
- Добавлены шаблоны **«Убить напарников»** и **«Выдать случайный тайник»**.
  Первый затрагивает только обычных NPC-напарников, второй штатно создаёт
  наводку, наполняет тайник, ставит метку и сообщает его локацию в КПК.
- Для одиночного и случайного спавна NPC добавлена возможность присваивать всем
  созданным персонажам имя донатчика.

## Исправления и интерфейс

- Исправлены отношения мутанта-напарника с игроком и его человеческими
  напарниками, следование, переходы между локациями и выход из слишком далёкого
  боя. Убраны постоянные переспавны и небезопасные точные команды перемещения.
- Устранён повторяющийся Lua-спам от недоступных конкретным классам методов
  движка. Добавлена проверка личности объектов, чтобы после переиспользования ID
  скрипт не управлял посторонним NPC.
- Мутант-напарник теперь всегда выбирается случайно из отмеченных секций;
  лишний переключатель случайного выбора удалён с сохранением совместимости со
  старыми настройками.
- Во всех списках с множественным выбором рядом со снятием отметок добавлена
  команда **«Выделить всё»**.
- Шаблоны мутанта-напарника и временного изменения параметров героя явно
  помечены как экспериментальные.

Игровой аддон обновлён до версии **1.0.54**. После распаковки новой версии
нажмите **«Установить / обновить аддон и эффекты»** и полностью перезапустите
игру. Программа обновлена до **1.0.94-beta.1**; пользовательские настройки,
шаблоны, история и токены продолжают храниться во внешней папке данных и не
заменяются архивом.

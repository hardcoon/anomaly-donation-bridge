**Anomaly Donation Bridge 1.3.9**

- В шаблоне «Заспавнить напарника с именем донатчика» добавлена настройка «Получаемый урон, %»: 100 — обычный урон, 50 — половина, 10 — десятая часть. По умолчанию — 100%. Настройка сохраняется вместе с NPC при загрузке сохранения.
- В шаблоне «Крутить рулетку» добавлена пауза на всё время окна, включая вращение и подтверждение результата. По умолчанию выключена. При включении появляется подсказка: запуск и подтверждение — клавишей прыжка, по умолчанию Пробел.

# Anomaly Donation Bridge 1.3.20

- **Напарник с именем данатчика (особый визуал):** исправлено обнаружение профилей внешности из модов через MO2, включая XML-подключения по маске. Сохраняется проверка совместимости моделей перед появлением NPC.
- **БТР-напарник:** добавлен чекбокс **«Legacy api управление»** для движка `AnomalyDX11-2026.5.15.exe`. По умолчанию выключен; для этого движка включите его в настройках шаблона.
- **Новая жизнь:** по умолчанию используется альтернативный запуск засыпания и пробуждения. Недоступность анимации, ошибка камеры или отсутствие сигнала её завершения больше не блокируют переселение и очередь эффектов.
- **Странствующий торговец:** по окончании таймера умирает. Если открыт разговор или торговля, ждёт закрытия окна. Убраны принудительное удаление NPC, отключение диалогов и повторная очистка товаров после смерти. После обработки смерти тело закрывается для обыска; уже открытое окно не закрывается принудительно. Купленные вещи сохраняются у игрока.
- **Данат-воришка:** штатная обработка лута после его смерти больше не удаляет украденные патроны и не ухудшает состояние украденного снаряжения. Защита сохраняется вместе с игрой и не меняет лут остальных NPC.

После обновления установите аддон **1.0.177** и эффекты через **Настройки → Игра и редактор → «Установить / обновить аддон и эффекты»**, полностью перезапустите игру и обновите каталог. Настройки, профили и голосования сохраняются. Ранее выданные отдельные исправления сканера и БТР распознаются установщиком.

Пройдены автоматические проверки и проверки обновления. Повторная проверка вылета при обыске торговца в настоящей игре пока не выполнена.

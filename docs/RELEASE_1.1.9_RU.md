# Anomaly Donation Bridge 1.1.9

Исправлено принудительное открытие диалога «Доставучего фаната» поверх обыска
трупа или ящика, из-за которого могло нарушаться состояние интерфейса.

В шаблон добавлен чекбокс «Безопасно закрывать штатные диалоги перед обращением»,
по умолчанию выключенный:

- Выключен — фанат ждёт, пока игрок сам закроет интерфейс.
- Включён — фанат штатно закрывает поддерживаемые окна и начинает разговор
  только после проверки завершения закрытия. Неизвестные окна и подтверждающие
  диалоги не прерываются.

Отложенное обращение не расходуется. Настройка фаната сохраняется в сейве;
для старых сохранений автоматическое закрытие остаётся выключенным.

После обновления нажмите «Установить / обновить аддон и эффекты» при закрытой
игре, затем запустите её заново. Основной аддон — 1.0.69; всего 48 файловых шаблонов.

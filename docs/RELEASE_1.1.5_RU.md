# Anomaly Donation Bridge 1.1.5

В настройки шаблона «Доставучий фанат» добавлен переключатель
**«Техническая группировка „Торговец“»**.

- По умолчанию переключатель выключен, и фанат по-прежнему получает
  группировку игрока.
- При включении NPC получает техническую community `trader`, которая
  нейтральна к основным группировкам и мутантам.
- Выбранный режим сохраняется вместе с состоянием фаната и восстанавливается
  после F9.

Программа обновлена до версии **1.1.5-rel**. Версия ядра игрового аддона остаётся
**1.0.68**, поскольку изменён отдельный файл шаблона. После распаковки ZIP
установите файлы шаблонов через **Настройки → Игра и редактор**, затем
полностью перезапустите игру.

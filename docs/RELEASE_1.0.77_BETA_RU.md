# Anomaly Donation Bridge 1.0.77 Beta

Добавлена полноценная интеграция DonateX:

- во вкладке **Настройки → Интеграция → DonateX** можно проверить и сохранить
  внешний токен из кабинета DonateX;
- новые донаты принимаются через официальный SignalR hub;
- после разрыва соединения программа восстанавливает пропущенные события через
  REST API, не запуская старые донаты при первом подключении;
- официальные лимиты REST API соблюдаются включённой по умолчанию защитой;
- внешний токен хранится в Windows DPAPI и не попадает в экспорт или лог;
- DonationAlerts и DonateX работают одновременно и независимо, а события из
  обоих источников поступают в общую последовательную очередь;
- ID событий содержат внутренний префикс источника, поэтому совпавшие номера
  двух сервисов не мешают дедупликации;
- ошибка или отключение одного сервиса не останавливает второй.

Игровой аддон не изменялся и остаётся версии 1.0.44. Переустанавливать его не
нужно — достаточно заменить программу и перезапустить её.

# Anomaly Donation Bridge 1.0.75 Beta

Доработаны настройки и навигация программы:

- в разделе **«Исключения»** по умолчанию показываются только уже исключённые
  секции; переключатель позволяет открыть весь просканированный каталог;
- добавлен фильтр исключений по типу: предметы, NPC, мутанты, отряды,
  аномалии, локации и группировки;
- поиск, фильтр, переключатель режима, ручное добавление и счётчик собраны в
  одну компактную строку;
- полосы прокрутки во всей программе стали шире, а их бегунок получил
  заметный минимальный размер на больших списках;
- верхняя вкладка **DonationAlerts** переименована в **«Интеграция»**;
- внутри раздела интеграций находятся вкладки **DonationAlerts** и **DonatX**;
  DonatX пока является безопасной заглушкой и ничего не подключает;
- порядок вкладок настроек изменён на: **Игра и редактор → Интеграция →
  Исключения → Очередь**, далее — остальные прежние разделы;
- исправлено вертикальное смещение вложенных вкладок при переключении между
  длинным содержимым DonationAlerts и короткой заглушкой DonatX.

Игровой аддон не изменялся и остаётся версии 1.0.44. Переустанавливать его для
этого обновления не требуется — достаточно заменить файлы программы и
перезапустить её.

# Anomaly Donation Bridge 1.0.74 Beta

Добавлен общий список пользовательских исключений игровых секций:

- в настройках появился отдельный раздел **«Исключения»** с поиском по живому
  каталогу и переключателями для предметов, NPC, мутантов, отрядов, аномалий,
  локаций и группировок;
- кнопка **«+ Добавить вручную»** позволяет внести точный ID битой секции,
  даже если сканер не смог показать её в каталоге;
- исключённая секция пропадает из доступных вариантов и блокируется при
  попытке выполнить ранее сохранённый пресет;
- игровой аддон перечитывает список перед каждой командой и исключает такие
  секции из собственных случайных выборок;
- в **Истории** появилась кнопка **«Добавить в исключения»**: одна конкретная
  секция добавляется сразу, для нескольких вариантов открывается окно с
  поиском и множественным выбором;
- исключения общие для всех профилей и сохраняются в настройках программы.

Версия аддона повышена до 1.0.44. После обновления программы нажмите
**«Установить / обновить аддон и эффекты»**, затем полностью перезапустите игру.

# Anomaly Donation Bridge 1.3.15

- **Чат YouTube:** подключение по API-ключу и ссылке на эфир. Ключ сохраняется один раз, подключение восстанавливается после перезапуска программы.
- **Голосования из чата:** один голос на YouTube-аккаунт за раунд с настраиваемым весом. Можно разрешить смену голоса и совместить чат с донатами. Повторы не увеличивают сумму, принятые голоса сохраняются после перезапуска.
- **Окно OBS:** одно окно для всех голосований с автоматическим переключением на активное. Проценты, сумма или таймер отображаются по общим настройкам с игровым HUD.
- Добавлен шаблон **«Отправить сообщение в КПК»**: ник донатера и текст описания. При победе в голосовании — название голосования и победившего шаблона. Подходит для варианта «Ничего не делать».

Добавлена инструкция по подключению чата YouTube со скриншотами.

После обновления установите/обновите эффекты через настройки программы и полностью перезапустите игру. Версия основного аддона остаётся **1.0.168**.

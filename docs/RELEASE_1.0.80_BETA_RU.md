# Anomaly Donation Bridge 1.0.80 Beta

## Новый шаблон

- Добавлен шаблон **«Сменить имя героя на имя донатчика»** в разделе
  **«Состояния игрока»**.
- Имя меняется штатным методом Anomaly
  `alife():actor():set_character_name(...)` — тем же серверным API персонажа,
  которое использует игровая настройка имени. Новое имя сохраняется в сейве.
- Имя донатчика очищается от управляющих символов, ограничивается безопасной
  длиной и переводится в Windows-1251 перед передачей игре.
- При ручном повторе этого шаблона используется имя исходного донатчика, а не
  подпись «Ручной повтор».

## Обновление

Версия игрового аддона повышена до **1.0.45**. После распаковки новой версии
откройте **Настройки → Игра и редактор** и нажмите
**«Установить / обновить аддон и эффекты»**, затем полностью перезапустите игру.

Автоматические проверки подтверждают регистрацию Lua-обработчика, передачу
имени донатчика, кодировку и комплектность поставки. Фактическая работа в
запущенной игре автоматически не проверялась.

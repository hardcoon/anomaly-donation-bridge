# Anomaly Donation Bridge 1.0.72 Beta

Изменено:

- в пресете **«Выдать предмет»** появились отдельные категории
  **«Случайная броня»** и **«Случайный шлем»**; выбор выполняется только среди
  доступных секций свежего безопасного каталога игры;
- добавлен чекбокс **«При выдаче оружия добавить патроны»** и количество пачек
  от 1 до 50 на каждую фактически выданную единицу оружия;
- совместимый тип патронов определяется по `ammo_class` выданного оружия — это
  работает как для выбранного вручную, так и для случайного оружия;
- если набор не выдаёт оружие или оно не использует патроны, настройка
  безопасно игнорируется и не мешает выдаче остальных предметов.

Версия аддона повышена до 1.0.42. После обновления программы нажмите
**«Установить / обновить аддон и эффекты»**, затем полностью перезапустите игру.

# Исходники и сборка

[← Первый запуск](../README.md)

В `main` опубликованы исходники программы **1.4.1** и аддона **1.0.182**. Готовый комплект остаётся в [GitHub Releases](https://github.com/hardcoon/anomaly-donation-bridge/releases/latest).

## Требования

- Windows x64: приложение использует WPF и Windows DPAPI.
- .NET 8 SDK. `global.json` разрешает установленную стабильную версию SDK ветки 8.0.
- PowerShell 7.
- Доступ к NuGet при первом восстановлении зависимостей.

Для компиляции и автоматических тестов установленная игра и ключи интеграций не нужны. Anomaly требуется для проверки эффектов в игре.

## Состав

| Каталог | Содержимое |
| --- | --- |
| `src` | Приложение, ядро, хранение данных, интеграции DonationAlerts, DonateX и YouTube, обмен с игрой, процесс восстановления после сбоя. |
| `game-addon` | Аддон, манифест с контрольными суммами и необходимые ресурсы. |
| `effects`, `optional-effects` | 70 поставляемых файловых шаблонов; при сборке объединяются в одну папку эффектов. |
| `tests` | Тесты C# и Lua, искусственные каталоги и данные для проверок. |
| `scripts` | Сборка, тесты, установка локального SDK и подготовка переносимого архива. |
| `third-party` | Лицензии и сведения об используемых сторонних компонентах. |

`game-addon/legacy-scripts` и отдельные файлы в `deferred-effects` нужны существующим регрессионным тестам. Они не устанавливаются в игру и не добавляются в комплект из 70 шаблонов.

## Сборка EXE

Откройте PowerShell 7 в корне клонированного репозитория:

```powershell
./scripts/build.ps1
```

Скрипт восстановит зависимости, соберёт решение, выполнит тесты C# и подготовит переносимую программу:

```text
artifacts/portable-win-x64/AnomalyDonationBridge.exe
```

Папки `addon-package`, `effects` и скрытую `_internal` оставьте рядом с EXE. Сборка не устанавливает аддон в игру и не запускает эффекты.

Если SDK не установлен, можно установить его локально в `work/dotnet8` и затем повторить сборку:

```powershell
./scripts/bootstrap-dotnet.ps1
./scripts/build.ps1
```

Для уже установленного SDK в отдельной папке:

```powershell
./scripts/build.ps1 -DotNetRoot 'D:\Tools\dotnet8'
```

## Проверки

Тесты C# можно запустить отдельно:

```powershell
./scripts/test.ps1
```

Для Lua нужен LuaJIT, совместимый с Lua 5.1. Исполняемый файл интерпретатора в репозиторий не включён:

```powershell
./scripts/test-lua.ps1 -LuaJitPath 'D:\Tools\LuaJIT\luajit.exe'
```

Lua-проверки выполняются с подставными игровыми API. Они не заменяют проверку на установленной сборке Anomaly.

Файлы аддона проверяются по SHA-256. Для них в `.gitattributes` отключено преобразование переводов строк; сохраняйте исходную кодировку и окончания строк при подготовке сборки.

## Переносимый ZIP

После успешной сборки:

```powershell
./scripts/stage-minimal-release.ps1 `
    -Version '1.4.1' `
    -ExpectedEffectCount 70 `
    -PublishedRoot './artifacts/portable-win-x64' `
    -ReadmePath './README.md' `
    -ReleaseNotesPath './docs/RELEASE_1.4.1_RU.md'
```

ZIP и `SHA256SUMS.txt` появятся в `artifacts/release-1.4.1`. Повторная подготовка архива заменяет эту локальную папку. Скрипт ничего не публикует на GitHub. Подробные инструкции из `docs` доступны в репозитории; минимальный ZIP содержит README без всего дерева документации.

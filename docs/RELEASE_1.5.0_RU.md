- **«Чат зрителей»** — единая лента сообщений YouTube, Twitch и VK Видео Live со значком площадки и цветными никами. Публичные чаты подключаются без аккаунта и своего API-ключа. Прежняя интеграция YouTube API оставлена как необязательная резервная.
- **Голосования из общего чата** — команды со всех трёх площадок участвуют в одном голосовании. Победитель поступает в общую очередь эффектов. История чата и повторно доставленные сообщения новых голосов не добавляют.
- **«Авто-формирование» голосований** — случайный набор из отмеченных активных или пользовательских шаблонов при каждом новом запуске. Можно выбрать **2–99 команд**, необязательный символ и формат: цифры или сокращения названий. Повторяющиеся сокращения получают номер; после паузы текущие команды и голоса сохраняются.
- **Отдельные окна чата, голосований и истории** — открываются через правую кнопку мыши по разделу и остаются видимыми при сворачивании главного окна. Подключения, настройки и очередь общие; закрытие окна возвращает раздел в программу.

**Для обновления с 1.4.9:** закройте ADB через трей и запустите программу из нового комплекта. Аддон **1.0.190** и **73 шаблона** не изменились; переустанавливать игровые файлы не требуется.

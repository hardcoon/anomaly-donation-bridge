# Anomaly Donation Bridge — тест голосований 1.3.0-voting.1

Это предварительная сборка. Стабильная версия — [1.2.3](https://github.com/hardcoon/anomaly-donation-bridge/releases/tag/v1.2.3-rel).

## Запуск

Распакуйте весь ZIP в отдельную папку и запускайте **AnomalyDonationBridge.exe** рядом с папками `_internal`, `addon-package` и `effects`. Для замены запущенной программы сначала завершите её через значок в трее. EXE можно переносить: пользовательские настройки хранятся отдельно в `%LOCALAPPDATA%\AnomalyDonationBridge`.

Версия аддона не менялась: **1.0.119**. Если он уже установлен, повторная установка ради голосований не нужна. Для первого подключения укажите папку игры в настройках и установите аддон/эффекты. Для полноценной работы некоторых шаблонов нужны [Modded Exes и соответствующие ресурсы](https://github.com/themrdemonized/xray-monolith); не смешивайте несовместимые пакеты движка и ресурсов. При MO2 укажите папку отдельного мода Anomaly Donation Bridge и включите её в менеджере.

## Как проверить голосования

1. Откройте «Голосования». Добавьте пустые строки кнопкой «+», задайте разные команды, например `!долг` и `!свобода`, и выберите для каждой активный шаблон. Другой путь — меню «⋯ → Добавить в голосование» у карточки шаблона.
2. Настройте сумму и/или время, валюту, заголовок. Нажмите «Сохранить», затем включите большой переключатель.
3. Для проверки без реальных денег введите тестовую сумму и сообщение с командой в блоке «Тестовый взнос» и нажмите «Внести». Такой взнос влияет на текущую рулетку, но не запускает обычный эффект по сумме. Не смешивайте тестовые взносы с настоящим эфирным сбором: перед эфиром нажмите «Новый сбор».
4. После выполнения условий станет доступна кнопка «Крутить». Она находится в программе, а не в игре или окне OBS. **Победивший шаблон будет действительно передан в игру**, даже если сбор набран тестовыми взносами.
5. «Вывести окно для захвата OBS» открывает отдельное окно с прозрачным фоном, прогрессом, кругом и списком команд. Его можно перетаскивать мышью; закрыть — через правую кнопку мыши → «Закрыть окно OBS». Поддержка прозрачности зависит также от метода захвата в OBS и проверяется отдельно.

При настоящем донате обычная обработка должна быть включена. Например, 100 рублей с сообщением `!долг` запускают прежний эффект на 100 рублей **и одновременно** прибавляют 100 рублей к этой команде. Голосование не перехватывает обычные донаты.

## Условия и сохранение

- **И:** сумма должна быть собрана за заданное время. Даже если её набрали раньше, ждём окончания срока. При недоборе рулетка недоступна.
- **ИЛИ:** сбор завершается при наборе суммы либо истечении времени — что раньше. Нулевой сбор не разыгрывается.
- Регистр команды не важен. Разные команды в одном сообщении считаются неоднозначными: взнос не попадает в голосование, обычный эффект работает независимо.
- Валюты не конвертируются. Взнос, превысивший оставшуюся цель, учитывается целиком.
- После старта команды и финансовые настройки фиксируются. Выключение переключателя ставит сбор и таймер на паузу. «Новый сбор» сохраняет предыдущий раунд в архиве и начинает новый с нулевыми суммами.
- Прогресс, ID учтённых донатов и победитель находятся в `%LOCALAPPDATA%\AnomalyDonationBridge\voting.json`. Не удаляйте и не заменяйте этот файл во время сбора. Рядом сохраняется предыдущий снимок `.bak`; при повреждении учёта программа не сбрасывает его молча.
- Активный таймер учитывает реальное время, включая закрытие программы. После перезапуска сохраняются тот же результат и тот же ID отправки; повторного розыгрыша нет. Неизвестный результат отправки смотрите в обычной истории, он не отправляется автоматически повторно.
- Раунд связан с профилем, в котором был запущен. Передача победителя из другого профиля ждёт возврата к исходному.

На первом этапе нет автозапуска, игровой рулетки, игрового HUD и автопаузы. Игра получает только итоговый эффект через прежнюю очередь.

Программа предоставляется «как есть». Репозиторий и обратная связь: [hardcoon/anomaly-donation-bridge](https://github.com/hardcoon/anomaly-donation-bridge).

# Anomaly Donation Bridge 1.0.76 Beta

Исправлено оформление окна настроек:

- окно по умолчанию стало шире, поэтому все верхние разделы, включая
  **«О программе»**, помещаются в одну строку;
- строка управления исключениями выровнена: поиск, фильтр, переключатель,
  ручное добавление и счётчик теперь имеют одинаковую высоту;
- подсказка в пустом поле поиска скрывается при получении фокуса и больше не
  накладывается на текстовую каретку;
- ширина глобальных полос прокрутки увеличена;
- исправлен расчёт бегунка на больших списках: WPF больше не может ужать его
  до почти невидимой чёрточки, минимальная видимая длина составляет 60 px;
- в разделе **«О программе»** появилась кнопка **«Проверить обновление»**;
  она проверяет опубликованные GitHub Releases, включая Beta, но ничего не
  скачивает;
- если найдена более новая версия, программа предлагает открыть её страницу
  в системном браузере;
- пользовательская терминология приведена к одному названию: **«Пресеты»**
  переименованы в **«Шаблоны»**, включая вкладки, кнопки, подсказки, профили,
  горячие клавиши и сообщения об ошибках; формат файлов и старые настройки при
  этом остаются совместимыми.

Для скроллбара добавлена отдельная проверка реальным WPF-рендером на диапазоне
почти из 10 000 элементов.

Проверка обновлений выполняется только по нажатию кнопки: без фоновой слежки,
автоматического скачивания или установки.

Игровой аддон не изменялся и остаётся версии 1.0.44. Переустанавливать его не
требуется — достаточно обновить программу и перезапустить её.

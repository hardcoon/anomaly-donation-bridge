# Шаблоны

[← Первый запуск](../README.md#4-настройте-первый-эффект) · [Суммы и очередь](USAGE_RU.md) · [Подготовка V2](INSTALL_RU.md#напарник-мутант-v2)

В версии **1.3.3** — **63 файловых шаблона**. Ниже — названия из программы и краткое назначение. Доступные секции и параметры берутся из вашей игры; полный набор настроек открывается кнопкой **«Настроить»**.

## NPC и мутанты

| Шаблон | Назначение |
| --- | --- |
| Босс-вертолёт | Боевой вертолёт со случайной моделью из отмеченных, заданием на уничтожение и денежной наградой. |
| Вертолёт-напарник | Вызывает вертолёт поддержки: он следует за игроком и атакует его врагов. |
| Данат-воришка | NPC крадёт вещи из рюкзака и убегает. При приближении на два метра погибает и оставляет украденное на теле. |
| Донат-босс | Создаёт на текущей локации одиночного NPC с именем донатчика. |
| Доставучий фанат | Безоружный NPC следует за героем и несколько раз принудительно начинает диалог; обычным напарником не считается. |
| Заспавнить мутантов | Создаёт выбранных мутантов из свежего безопасного каталога установленной игры. |
| Заспавнить напарника с именем донатчика | Создаёт выбранного или случайного NPC как настоящего напарника, даёт ему имя донатчика и сохраняет в отряде при переходах между локациями. |
| Заспавнить NPC | Создаёт выбранных NPC из свежего безопасного каталога установленной игры. |
| Напарник-мутант (legacy) | Создаёт одного настоящего мутанта без симуляционного отряда. |
| Напарник-мутант V2 | Мутант с именем донатера и меню команд: следование, ожидание, отдых и режимы боя. |
| Переименовать ближайшего важного NPC | Переименовывает ближайшего живого важного NPC на текущей локации в ник донатера и сообщает об этом в КПК. |
| Случайные мутанты (без сквада) | Выбирает мутанта из разрешённых секций и создаёт отдельных существ, а не симуляционный отряд. |
| Случайные NPC (без сквада) | Выбирает NPC из разрешённых секций и создаёт отдельных персонажей, а не симуляционный отряд. |
| Убить напарников | Убивает выбранное число случайных обычных NPC-напарников. |

## Симуляция

| Шаблон | Назначение |
| --- | --- |
| Случайный сквад мутантов (вызывает проблемы) | Создаёт один из настоящих отрядов мутантов текущей сборки игры. |
| Случайный сквад NPC (вызывает проблемы) | Создаёт настоящий отряд выбранной группировки прямо возле персонажа. |
| Спавн отряда мутантов (вызывает проблемы) | Создаёт выбранные полноценные сквады мутантов прямо возле персонажа. |
| Спавн отряда NPC (вызывает проблемы) | Создаёт выбранные полноценные сквады NPC прямо возле персонажа. |

## Состояния игрока

| Шаблон | Назначение |
| --- | --- |
| Временно изменить параметры героя | На указанное время увеличивает или уменьшает высоту прыжка, скорость бега и переносимый вес, затем возвращает прежние значения. |
| Временно отключить HUD | Штатной консольной командой скрывает HUD на выбранное время, затем возвращает прежнее состояние. |
| Год-мод | Блокирует входящий урон; раз в секунду снимает радиацию и кровотечение, восстанавливает пси-здоровье. |
| Деменция | На указанное время случайно переставляет назначенные игроком клавиши внутри выбранных групп действий. |
| Добавить радиацию | Изменяет уровень радиационного заражения актёра. |
| Замедление времени | Временно замедляет весь игровой мир, включая героя, анимации и звуки. |
| Заставить персонажа поспать | Запускает штатное затемнение и пробуждение, сдвигает время и применяет обычные последствия сна. |
| Изменить голод и жажду | Положительное значение утоляет голод или жажду, отрицательное усиливает, ноль не меняет шкалу. |
| Изменить группировку игрока | Случайно выбирает одну из отмеченных группировок текущей сборки и меняет группировку персонажа. |
| Изменить здоровье | Добавляет или отнимает процент здоровья. |
| Наложить эффект опьянения | Включает штатный эффект опьянения на выбранное время без предметов. |
| Новая жизнь | Переселяет в случайного обычного сталкера, сохраняя задания и напарников. Перенос инвентаря и группировка настраиваются. |
| Постоянно изменить параметры героя | Навсегда для текущего сохранения увеличивает или уменьшает высоту прыжка, скорость и переносимый вес. |
| Сделать разминку WASD | Блокирует действия движения и взаимодействия, пока игрок не повторит показанную последовательность своих назначенных клавиш. |
| Случайный телепорт | Перемещает персонажа на безопасную вершину текущей локации. |
| Сменить имя героя на имя донатчика | Штатно меняет имя персонажа на имя донатчика. |
| Сыграть на гитаре | Герой садится и играет случайную отмеченную композицию; камера свободно вращается, Esc прерывает исполнение. |

## Метаморфозы

| Шаблон | Назначение |
| --- | --- |
| Превратиться в бюрера | Форма бюрера: гравиволна, телекинез предметов и трупов, ближняя атака и щит. |
| Превратиться в контролёра | Форма контролёра: переключаемые пси-способности, прицеливание и ближняя атака. |
| Превратиться в кровососа | Форма кровососа: удары с восстановлением HP формы и невидимость, во время которой нельзя атаковать. |
| Превратиться в полтергейста | Парящий полтергейст: временные аномалии с выбором типа и телекинез. |
| Превратиться в псевдогиганта | Форма псевдогиганта: ближняя атака и удар ногой с ударной волной. |
| Превратиться в тушкана | Форма тушкана: укус и прыжок; здоровье, урон и высота прыжка настраиваются. |

## Инвентарь

| Шаблон | Назначение |
| --- | --- |
| Выбить оружие | Выбивает текущее оружие один раз либо не даёт удерживать оружие в руках в течение выбранного времени. |
| Выбросить случайный предмет | Выбрасывает указанное число случайных безопасных предметов из любых типов и стаков; если их меньше — выбрасывает все доступные. |
| Выдать патроны к снаряжению | Выдаёт полные пачки патронов к оружию в отмеченных слотах. |
| Выдать предметы в инвентарь | Добавляет выбранные предметы из безопасных категорий игрового спавнера. |
| Заблокировать инвентарь | Штатным callback Anomaly запрещает открывать обычный инвентарь в течение выбранного времени. |
| Изменить деньги | Положительная сумма добавляет игровые деньги, отрицательная — отнимает. |
| Использовать случайный расходник | Штатно использует случайную еду, напиток или медицинский предмет и расходует одно применение. |
| Крутить рулетку | Рулетка на заданное число круток: ставка предметом из инвентаря, потеря при проигрыше или замена наградой той же категории. |
| Повредить экипировку | Уменьшает текущее состояние брони, шлема или обоих предметов на выбранный процент. |
| Снять экипировку | Штатно снимает броню, шлем или оба предмета и оставляет их в инвентаре. |

## Мировые события

| Шаблон | Назначение |
| --- | --- |
| Выдать случайный тайник | Штатно выдаёт наводку на случайный доступный тайник, наполняет его, ставит метку и сообщает фактическую локацию в КПК. |
| Вызвать выброс | Запускает штатный выброс на текущей локации, если он доступен и ещё не идёт. |
| РАЗРЫВНАЯ | Создаёт перед героем выбранную случайную ручную гранату, которую нельзя подобрать; она падает и взрывается. |
| Рандом по ВСЕМ шаблонам | Выбирает эффект из отмеченных обычных шаблонов и создаёт безопасные случайные параметры; выдача предметов всегда исключена. |
| Рандомный по активным шаблонам | При срабатывании выбирает один из остальных доступных активных вариантов. |
| Рассказать анекдот | Находит реальные звуковые реплики анекдотов в установленной игре и модах и проигрывает случайную реплику от лица героя. |
| Собрать лут и убрать трупы | Переносит лут обычных трупов в один рюкзак у ног героя и удаляет опустевшие тела в указанном радиусе. |
| Создать временную аномалию | Создаёт вокруг героя равномерное кольцо временных аномалий выбранного либо случайного типа. |
| Стационарный пулемёт | Создаёт рядом штатный управляемый пулемёт с бесконечными патронами. |
| Телепортация на случайную локацию | Выбирает одну из отмеченных локаций и после загрузки перемещает персонажа в случайную доступную точку по всей карте. |
| Убить ближайших NPC | Убивает всех живых NPC в заданном радиусе от игрока. |
| Удалить последние N сохранений | Убирает последние N сохранений из списка загрузки; 999 означает все. |

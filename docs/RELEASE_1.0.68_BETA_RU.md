# Anomaly Donation Bridge 1.0.68 Beta

Добавлено:

- в **Настройки → Общие настройки** появились два независимых переключателя:
  создание сохранения перед выполнением эффектов и после их завершения;
- если одной сумме назначено несколько пресетов, сохранение создаётся один раз
  перед всей цепочкой и один раз после завершения всей цепочки;
- для каждого действительно запущенного пресета игра показывает отдельную
  техническую строку `Имя донатчика — Название пресета`;
- строки нескольких пресетов выводятся по очереди и не используют сообщение КПК;
- техническая строка занимает отдельное место HUD и не затирает штатное
  уведомление игры о сохранении;
- настройки сохранений применяются также к локальному тесту, горячим клавишам,
  ручному повтору и «Колесу фортуны».

Версия аддона повышена до 1.0.39. После обновления программы нажмите
**«Установить / обновить аддон и эффекты»** и полностью перезапустите игру.

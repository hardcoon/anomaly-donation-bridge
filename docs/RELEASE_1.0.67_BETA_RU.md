# Anomaly Donation Bridge 1.0.67 Beta

Исправления и изменения:

- **«Рассказать анекдот»** теперь воспроизводит найденную реплику в штатном для
  героя двухмерном режиме звука. Раньше движок успешно запускал 3D-источник на
  самом объекте игрока и сообщал о выполнении, но камера-слушатель могла его не
  слышать;
- поиск реальных `joke_*.ogg` в игровых архивах и модах сохранён без изменений;
- в компактных строках **Активных** добавлена быстрая кнопка **«+ Сумма»**;
- лишняя ручная кнопка **«Удиви меня»** убрана из раздела пользовательских
  пресетов; случайные события через пресеты и «Колесо фортуны» сохранены;
- в подробностях выполненного события теперь появляется
  `actor_joke_played_2d_pool_N`, что позволяет отличить исправленную версию.

Версия аддона повышена до 1.0.38. После обновления программы нажмите
**«Установить / обновить аддон и эффекты»** и полностью перезапустите игру.

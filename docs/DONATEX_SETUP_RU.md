# Подключение DonateX

## Что понадобится

Для подключения одного стримера DonateX выдаёт бессрочный внешний токен.
Создавать OAuth-приложение, Client ID или Client Secret не требуется.

1. Откройте кабинет DonateX и перейдите в **Настройки → API**.
2. Скопируйте внешний токен.
3. В Anomaly Donation Bridge откройте **Настройки → Интеграция → DonateX**.
4. Вставьте токен и нажмите **Подключить DonateX**.

После проверки рядом появится имя подключённого аккаунта. Никому не
передавайте токен и не публикуйте его в логах или скриншотах.

## Одновременная работа сервисов

Отключать DonationAlerts не нужно. DonationAlerts и DonateX держат отдельные
соединения, отдельные токены и контрольные точки восстановления. Донаты из
обоих источников поступают в одну последовательную очередь и используют один
набор активных шаблонов и сумм.

Если один сервис временно недоступен, второй продолжает принимать события.
Одинаковые внутренние номера разных сервисов не конфликтуют: программа
добавляет к ним префикс источника перед проверкой дублей.

## Защита API

Переключатель **Защита DonateX API** включён по умолчанию. Он ограничивает
исходящие REST-запросы официальными пределами DonateX: 10 запросов в секунду,
600 в минуту и 10 000 в час. Живые донаты приходят через SignalR и этой
задержкой не затрагиваются.

Токен сохраняется в `%LocalAppData%\AnomalyDonationBridge` с защитой Windows
DPAPI для текущего пользователя. Он не входит в экспорт настроек.

## Если донаты не приходят

- проверьте имя аккаунта рядом с кнопкой подключения;
- не удаляйте и не перевыпускайте токен во время работы программы;
- оставьте программе доступ к `https://donatex.gg` в брандмауэре;
- отключите DonateX в программе, создайте новый внешний токен и подключитесь
  заново, если старый токен был отозван.
- начиная с версии 1.0.79 программа автоматически проверяет все официальные
  варианты передачи внешнего токена и удаляет невидимые символы, случайно
  попавшие в буфер обмена.

Официальное описание токена, REST API, лимитов и события `DonationCreated`:
[DonateX API](https://donatex.gg/api-docs).

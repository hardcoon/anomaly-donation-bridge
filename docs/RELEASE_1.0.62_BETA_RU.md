# Anomaly Donation Bridge 1.0.62 Beta

Исправлены четыре связанные проблемы:

- временное усиление героя больше не сбрасывается после F9 или перехода между локациями; оставшееся время и исходные характеристики сохраняются в игре;
- эффект опьянения восстанавливается после F9 и продолжает отсчёт с прежним оставшимся временем;
- напарник получает имя донатчика; при локальном тесте используется имя «Локальный тест»;
- заголовки, названия профилей и системные заголовки окон профилей приведены к цветам выбранной темы.

Версия аддона повышена до 1.0.33. После обновления программы нажмите
«Установить / обновить» в настройках и полностью перезапустите игру.

# Anomaly Donation Bridge 1.3.0-voting.1 — тест голосований

Предварительная сборка для проверки новой функции. Стабильная версия 1.2.3 остаётся доступной отдельно.

Добавлено:

- Кнопка «Голосования» и отдельное окно: настройки слева, команды и привязанные шаблоны справа.
- Взносы по произвольной команде в сообщении доната, без отмены обычных эффектов по сумме.
- Сумма сбора и/или срок, валюта RUB по умолчанию, ручная кнопка «Крутить».
- Прозрачное окно OBS: прогресс сверху, круг с долями слева, команды справа; текст с тенью.
- Добавление активного шаблона либо через меню «⋯ → Добавить в голосование» у карточки.
- Тестовые взносы без обычного эффекта доната. После ручного вращения победивший шаблон действительно передаётся в игру.
- Сохранение прогресса, защита от повторного учёта донатов, зафиксированный победитель и передача в существующую очередь с постоянным ID.

Условия:

- **И**: ждём окончания срока; рулетка доступна, если к этому моменту собрана нужная сумма. Недобор не запускает рулетку.
- **ИЛИ**: сбор закрывается при наборе суммы или истечении срока — что раньше. При нулевой сумме рулетка недоступна.
- После старта финансовые настройки и команды фиксируются. Переключатель выключения приостанавливает сбор и таймер, не стирая прогресс. «Новый сбор» архивирует текущий результат и обнуляет суммы нового раунда.
- Таймер активного сбора продолжается по реальному времени при закрытой программе. Поздно доставленный донат с датой внутри периода сбора может быть учтён до выбора победителя.
- Команды ищутся буквально, без учёта регистра, с границами слов. Если сообщение содержит разные команды сразу, взнос не учитывается в голосовании; обычный эффект не отменяется.
- Валюты не конвертируются и не складываются друг с другом. Взнос целиком учитывается, даже если превышает остаток до цели.

На этом этапе нет автозапуска, игровой рулетки, игрового HUD или автопаузы.

Аддон остаётся **1.0.119**. Для самой функции голосований обновление игровых файлов не требуется, если эта версия аддона уже установлена. Победившие шаблоны используют прежний протокол и очередь. Если игра отключена, эффект ждёт её подключения; каталогозависимый шаблон — свежего каталога. При неизвестном результате отправки автоматического повторения нет: смотрите историю программы.

Первый тест: добавьте два шаблона, пропишите разные команды, задайте небольшую цель, сохраните и включите сбор. Внесите тестовые суммы, затем нажмите «Крутить». Для настоящих донатов должна быть включена обычная обработка донатов.

Прозрачное окно можно перемещать мышью; закрывается через его контекстное меню по правой кнопке. Реальный захват прозрачности в OBS и поведение эффектов в вашей сборке игры требуют отдельной пользовательской проверки. Автоматические проверки не заменяют тест в игре.

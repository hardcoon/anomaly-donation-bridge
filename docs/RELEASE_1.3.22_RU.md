# Anomaly Donation Bridge 1.3.22

Исправлено управление БТР на Modded Exes 2026.5.15, включая MT TEST, при включённом **«Legacy api управление»**. БТР больше не останавливается при запуске управления из-за требования метода физики, отсутствующего в старом API.

При выключенном чекбоксе прежний способ управления сохранён. Legacy остаётся выключенным по умолчанию.

Обновите аддон до **1.0.179** через **Настройки → Игра и редактор → Установить / обновить аддон и эффекты**, затем полностью перезапустите игру. Для движка 2026.5.15 включите **«Legacy api управление»** в настройках БТР.

Проверено автоматическими тестами совместимости старого и нового API. Проверка в настоящей игре проводится отдельно.

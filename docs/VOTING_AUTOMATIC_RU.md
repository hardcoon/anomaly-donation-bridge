# Автоматическое формирование голосования

В голосовании включите кнопку с чекбоксом **«Авто-формирование»** и один раз
задайте его параметры. У каждого голосования собственные настройки.

1. Выберите источник: **Активные** или **Пользовательские** шаблоны текущего профиля.
2. Раскройте список и отметьте нужные шаблоны. Изначально выбраны все.
3. Задайте количество команд: **2–99**. Шаблоны внутри одного запуска не повторяются.
4. При необходимости укажите один символ перед командой, например **!** или **#**.
   Пустое поле означает команды без префикса.
5. Выберите **Цифра** или **Сокращение**. При наведении на вопросительный знак
   появляется большая подсказка с отдельными примерами названий и команд.

Параметры занимают две строки: источник и выбор шаблонов сверху, количество,
символ и формат снизу. В узкой области поля переносятся в три или четыре строки
без уменьшения текста. Кнопка **«Свернуть»** оставляет краткую сводку и освобождает
место для команд. Кнопка **«Параметры»** возвращает поля. Состояние панели
запоминается отдельно от правил голосования; сворачивание не меняет текущий раунд.

При первом старте и каждом новом раунде программа заново случайно выбирает
шаблоны из отмеченных, берёт их актуальные названия и настроенные параметры
и формирует команды. То же происходит при автоматическом переходе к голосованию.
Добавлять команды вручную в этом режиме не требуется.

Например, первое голосование может каждый раз выбирать два активных шаблона,
а второе — десять пользовательских. Списки выбора и параметры остаются независимыми.

| Название | Сокращение с символом ! |
| --- | --- |
| БТР атакует | !БА |
| Напарник с именем донатчика | !НСИД |
| Случайный телепорт | !СТ |
| Странствующий торговец | !СТ2 |

Цифровые команды нумеруются с единицы: **!1**, **!2**, **!3**. Повторяющиеся
сокращения получают числовой суффикс, поэтому команды всегда различаются.

Если корректных отмеченных шаблонов меньше нужного количества, запуск
недоступен до изменения выбора или количества.

Параметры сохраняются автоматически. Изменение правил формирования не заменяет
команды и накопленные голоса уже запущенного раунда: новые правила применяются
к следующему запуску. Продолжение после паузы и перезапуск программы сохраняют
текущий список и прогресс. Кнопка «Сбросить» сохраняет смысл сброса прогресса.

Источник голосов **«Чат зрителей»** объединяет YouTube, Twitch и VK Видео Live.
Победитель поступает в существующую общую очередь эффектов. Её статус виден
и во вкладке «Чат зрителей».

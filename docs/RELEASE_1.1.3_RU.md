# Anomaly Donation Bridge 1.1.3

В шаблон «Заставить персонажа поспать» добавлен альтернативный способ сна для
сборок, в которых штатный вариант не работает.

- Обычный штатный способ сна не изменён и используется по умолчанию.
- В настройках шаблона появился чекбокс **«Альтернативный способ сна (если
  обычный вариант не работает)»**; по умолчанию он выключен.
- Альтернативный вариант не зависит от `ui_sleep_dialog.script`: он выполняет
  затемнение и пробуждение, сдвигает игровое время и применяет стандартные
  последствия сна.
- После завершения управление, HUD и оружие восстанавливаются. Предусмотрена
  безопасная очистка при F9, смене уровня и несрабатывании анимационного
  callback.

Программа обновлена до версии **1.1.3-rel**. Версия игрового аддона остаётся
**1.0.65**, поскольку изменён отдельный файл шаблона, а не ядро аддона. После
распаковки нового ZIP установите аддон и файлы шаблонов через **Настройки → Игра
и редактор**, затем полностью перезапустите игру.

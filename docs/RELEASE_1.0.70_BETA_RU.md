# Anomaly Donation Bridge 1.0.70 Beta

Изменено:

- при ручном повторе пресета **«Заспавнить напарника с именем донатчика»** используется имя донатчика из исходной записи истории;
- для остальных пресетов ручной повтор по-прежнему показывает имя **«Ручной повтор»**;
- чекбокс игрового HUD-журнала переименован в **«Выводить надписью по центру»**;
- добавлен независимый чекбокс **«Выводить сообщение в КПК»**;
- оба варианта используют формат `Имя донатчика: Название пресета` вместо длинного тире;
- в сообщении КПК имя донатчика выделяется золотистым цветом.

Версия аддона повышена до 1.0.41. После обновления программы нажмите
**«Установить / обновить аддон и эффекты»** и полностью перезапустите игру.

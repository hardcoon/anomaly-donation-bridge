# Anomaly Donation Bridge 1.1.0

## Кольца аномалий

Шаблон временного создания аномалий теперь формирует вокруг игрока кольцо из
1–100 объектов с радиусом от 0 до 100 метров. Одиночная аномалия появляется
перед игроком. Можно один раз случайно выбрать общий тип для всего кольца либо
делать случайной каждую аномалию отдельно.

## Безопасный случайный телепорт

В шаблон телепортации добавлен режим **«Только посещённые локации»**. Сначала
учитывается выбранный пользователем набор уровней, затем исключения и текущая
локация, после чего остаются только уже посещённые уровни. Телепортация на
текущую локацию исключена.

## Группировка активных пресетов

Два и более активных пресета с одной суммой автоматически отображаются в общем
разворачиваемом разделе. Группа получает единый порядковый номер, собственное
локальное название, общий тестовый запуск и массовое изменение суммы. Это
визуальная группировка: существующие профили и сами пресеты не объединяются и
не требуют миграции. Представление работает в обычном, компактном и сеточном
режимах.

## Спавн NPC, мутантов и «Донат-босс»

- Убрана ненадёжная ручная фильтрация по силе секции: для подходящих шаблонов
  используется штатный вариант `any`.
- Для «Донат-босса» добавлен мультивыбор допустимых NPC; конкретный вариант
  выбирается случайно при срабатывании.
- Исправлено соблюдение заданного радиуса при создании временных аномалий.

## Мутант-напарник

- Добавлена отметка напарника на карте КПК.
- При наведении прицела показывается компактная подпись **«имя: N% HP»** без
  отдельной шкалы здоровья.
- Если игрок отдалился более чем на 100 метров, напарник выходит из боя и
  возвращается к игроку.
- Убрано вмешательство в домашнюю точку мутанта, из-за которого могли
  появляться быстро растущие ошибки `invalid dest_level_vertex_id`. Напарник
  использует штатную навигацию, боевое поведение и следование.

## Обновление

Программа обновлена до версии **1.1.0-rel**, игровой аддон — до версии
**1.0.60**. После распаковки нового ZIP установите аддон и файлы шаблонов через
**Настройки → Игра и редактор**, затем полностью перезапустите игру.
Пользовательские настройки, профили, история и подключения сохраняются.

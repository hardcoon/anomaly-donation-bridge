# Настройка интеграции

[← Первый запуск](../README.md#первый-запуск)

Откройте **Настройки → Интеграция** и выберите сервис:

- **[DonationAlerts](DONATIONALERTS_SETUP_RU.md)** — подключение через собственное OAuth-приложение: Client ID и Client Secret.
- **[DonateX](DONATEX_SETUP_RU.md)** — подключение по внешнему токену из кабинета.
- **[Чат YouTube](YOUTUBE_CHAT_SETUP_RU.md)** — ключ API и ссылка на текущий эфир для голосований из чата.

DonationAlerts и DonateX можно подключить одновременно. Их донаты поступают в общую очередь и используют один набор активных шаблонов. Сообщения YouTube учитываются только в голосованиях.

После подключения проверьте, что в настройках отображается нужный аккаунт. Для запуска эффектов от новых донатов включите **«Обработку донатов»** в главном окне программы.

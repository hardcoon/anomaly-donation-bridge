# Настройка интеграции

[← Первый запуск](../README.md#первый-запуск)

Откройте **Настройки → Интеграция** и выберите сервис:

- **[DonationAlerts](DONATIONALERTS_SETUP_RU.md)** — подключение через собственное OAuth-приложение: Client ID и Client Secret.
- **[DonateX](DONATEX_SETUP_RU.md)** — подключение по внешнему токену из кабинета.
- **[YouTube API](YOUTUBE_CHAT_SETUP_RU.md)** — необязательный резервный способ чтения YouTube по своему API-ключу.

DonationAlerts и DonateX можно подключить одновременно. Их донаты поступают в общую очередь и используют один набор активных шаблонов.

Основное подключение чатов находится в отдельном разделе **[«Чат зрителей»](VIEWER_CHAT_RU.md)** в левой панели. Он объединяет **YouTube, Twitch и VK Видео Live** в одну ленту. Укажите публичный эфир или канал: аккаунт и свой API-ключ не нужны. Сообщения учитываются в голосованиях с включённым источником **«Чат зрителей»**. Победитель поступает в общую очередь эффектов; обычное сообщение само по себе игровой шаблон не запускает.

После подключения проверьте, что в настройках отображается нужный аккаунт. Для запуска эффектов от новых донатов включите **«Обработку донатов»** в главном окне программы.

# Anomaly Donation Bridge 1.4

- **Новая жизнь (Азазель)** — пока действует шаблон, смерть заменяется переселением в подходящего живого NPC. По умолчанию действует 180 секунд, сначала выбирает напарника и сохраняет группировку. Можно включить поиск на других локациях и сохранение инвентаря. Задания, деньги и остальные напарники сохраняются. Таймер «Азазель: N сек.» показан внизу экрана и хранится в сейве. Если подходящих тел нет, герой умирает обычным способом.
- **Новая жизнь** — добавлена включённая по умолчанию настройка «Оставлять напарников прошлому телу». Обычные человеческие напарники образуют группу с прошлым телом; квестовые сопровождаемые остаются у игрока. Настройку можно отключить.
- **Телепортация по прицелу** — 1–99 повторений с интервалом 1–600 секунд. По умолчанию три переноса через три секунды. Точка под прицелом определяется перед каждым переносом; неподходящие места пропускаются. Серия переживает сохранения и быстрые загрузки в рамках запущенной игры. Полное закрытие игры завершает её.
- **Рандом по выбранным активным шаблонам** заменяет «Рандом по ВСЕМ шаблонам». В настройках выбираются конкретные активные варианты текущего профиля; победивший вариант запускается со своими параметрами. В старых экземплярах рандома нужно заново отметить участников.
- **Метаморфозы** — во всех шести формах выносливость поддерживается полной. После выхода из формы обычный расход возобновляется. Гравиволна бюрера на ЛКМ попадает по области прицела и проходит сквозь препятствия.
- **Группы шаблонов** — перетаскивание шагов теперь работает и в сетке. Захватите значок ⠿ рядом с номером шага и перенесите его на нужную карточку.
- **Кнопки и значки** — действия в карточках и компактном списке остаются в одной строке. Если подписи не помещаются, остаются иконки с подсказками. «В пользовательский шаблон» переименовано в «В пользовательские». Значки добавлены также во вкладки и верхние кнопки приложения.
- **Поиск** — всегда виден текстовым полем, включая компактный режим. Ctrl+F переводит курсор в поле, Escape и крестик очищают запрос.

После обновления с публичной версии установите аддон **1.0.181** и эффекты через **Настройки → Игра и редактор → Установить / обновить аддон и эффекты**, затем полностью перезапустите игру. Настройки, профили и голосования сохраняются. Если уже установлена проверенная **1.3.23-local.5**, достаточно заменить программу: аддон и эффекты в 1.4 те же.

Пройдены автоматические проверки программы, игровых скриптов и интерфейса. Перед выпуском пользователь подтвердил работу локальной сборки в игре.

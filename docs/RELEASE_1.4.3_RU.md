# Anomaly Donation Bridge 1.4.3

- Обновлено окно голосований. Слева виден список с отметкой **«В эфире»**, в центре компактные команды с суммами, процентами и полосой доли, справа сворачиваемые **«Настройки»**.
- Нижняя панель показывает текущий эфир и его прогресс. В ней доступны **«Запустить»**, **«Продолжить»**, пауза и ручной розыгрыш. Текущий эфир виден при редактировании другого голосования.
- Выбор **И / ИЛИ** показывается между суммой и временем, когда включены оба условия.
- По правому клику на строку можно запустить, приостановить или продолжить голосование, переименовать его, сбросить прогресс или удалить. В шапке остаются **«Сбросить»** и красная корзина. Сброс и удаление требуют подтверждения.

Для перехода с **1.4.2** закройте ADB через трей и запустите EXE из нового комплекта. Подходит установленный аддон **1.0.183** с эффектами из 1.4.2.

[Инструкция по голосованиям](https://github.com/hardcoon/anomaly-donation-bridge/blob/v1.4.3/docs/USAGE_RU.md#голосования).

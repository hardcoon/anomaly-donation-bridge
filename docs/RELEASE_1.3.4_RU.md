# Anomaly Donation Bridge 1.3.4

- Главное окно можно уменьшить до **640×520**.
- При ширине меньше 1080 или высоте меньше 680 автоматически включается компактный вид. При растягивании возвращается прежняя компоновка, без изменения размера текста.
- Статусы сведены в одну строку, категории — в выпадающий список, дополнительные суммы — под **«ещё»**, действия — в **«⋯»**. Кнопки **«Настроить»** и **«Тест»** остаются на виду.
- Поиск, фильтры, группы с перетаскиванием шагов и история работают в обоих режимах. Выбранный для большого окна вид списков сохраняется.

Аддон **1.0.135**, протокол и все **63 шаблона** не изменились. При переходе с 1.3.3 достаточно заменить программу; переустанавливать аддон не требуется.

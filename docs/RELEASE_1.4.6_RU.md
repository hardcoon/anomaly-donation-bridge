# Anomaly Donation Bridge 1.4.6

- Поиск шаблонов выполняется в фоне с отменой устаревших запросов. При быстром вводе применяется последний запрос.
- Вкладки **«Активные»**, **«Пользовательские»**, **«Шаблоны»** и категории используют порционную отрисовку карточек, включая раскрытые группы. Во время обновления доступны ввод и переход в другой раздел.
- После изменения набора шаблонов обновляется открытая вкладка. Остальные списки готовятся при переходе к ним.

Для обновления с **1.4.5** закройте ADB через трей и запустите EXE из нового комплекта. Подходит установленный аддон **1.0.183** с эффектами из 1.4.5.

[Поиск и настройка шаблонов](https://github.com/hardcoon/anomaly-donation-bridge/blob/v1.4.6/docs/USAGE_RU.md#шаблоны-и-активные-варианты)

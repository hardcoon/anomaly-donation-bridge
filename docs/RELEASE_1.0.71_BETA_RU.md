# Anomaly Donation Bridge 1.0.71 Beta

Изменено:

- в пресете **«Выбросить случайный предмет»** верхний предел увеличен с 10 до 999;
- если в инвентаре меньше указанного количества подходящих предметов, пресет выбрасывает все доступные предметы и завершается без ошибки;
- одинаковый предел применяется в интерфейсе и игровом Lua-скрипте.

Версия аддона остаётся 1.0.41: основные файлы аддона не изменились. После
обновления программы нажмите **«Установить / обновить аддон и эффекты»**, чтобы
установить обновлённый файл пресета, затем полностью перезапустите игру.

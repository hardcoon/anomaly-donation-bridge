# Anomaly Donation Bridge 1.0.60 Beta

Исправлена смена группировки игрока.

- Новая группировка записывается как постоянная группировка актёра, а не только
  во временное состояние текущей локации.
- После перехода между локациями игра больше не должна возвращать прежнюю
  группировку.
- Смена выполняется через штатный механизм Anomaly, включая обновление
  `default_faction` и отношений с группировками.

Версия аддона повышена до 1.0.31. После обновления программы нажмите
**Установить / обновить аддон и эффекты** и полностью перезапустите игру.

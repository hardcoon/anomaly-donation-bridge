# Anomaly Donation Bridge

Донаты DonationAlerts и DonateX запускают выбранные вами эффекты в S.T.A.L.K.E.R. Anomaly 1.5.3.
Оба сервиса можно подключить одновременно: программа собирает события в одну
последовательную очередь. Для Windows x64. Версия программы — 1.0.94 Beta,
аддона — 1.0.54.

Изменения версии: [новые игровые шаблоны и развитие мутанта-напарника](docs/RELEASE_1.0.94_BETA_RU.md).

## Установка

Скачайте [ZIP с программой](https://github.com/hardcoon/anomaly-donation-bridge/releases/download/v1.0.94-beta.1/AnomalyDonationBridge-1.0.94-beta.1-win-x64.zip),
распакуйте целиком в удобную папку и запустите `AnomalyDonationBridge.exe`.
Папки `addon-package` и `effects` оставьте рядом с программой. В архиве нет
рабочих документов, старых скриптов, пользовательских настроек и истории.

Закройте игру. В **Настройки → Игра и редактор** укажите папку Anomaly,
дождитесь автоматической проверки и при необходимости нажмите
**Установить / обновить аддон и эффекты**. Одна кнопка устанавливает игровой
аддон и все выбранные файлы шаблонов; после установки полностью перезапустите
игру.

![Выбор папки игры и установка аддона](docs/readme/01-game-setup.png)

При использовании MO2 укажите в настройках корень отдельного включённого мода
для файлов шаблонов, затем нажмите общую кнопку установки. Игровой аддон
программа установит в указанную папку игры, а шаблоны — в мод MO2.

Файлы шаблонов лежат в `effects\gamedata\scripts` рядом с EXE. Можно удалить
ненужные или добавить свои `.script` до установки: один файл — один шаблон.
Карточка появляется только после установки файла в игру и перезапуска игры.
Прежние пользовательские шаблоны и суммы сохраняются.

## Подключение DonationAlerts

В **Настройки → Интеграция → DonationAlerts** нажмите **Открыть OAuth-приложения**.
На сайте создайте новое приложение с любым понятным названием, например
`Anomaly Donation Bridge`. В поле **URL перенаправления** вставьте этот адрес
целиком, включая последний `/`, и сохраните:

```text
http://127.0.0.1:17871/donationalerts/callback/
```

![Настройки DonationAlerts и адрес возврата](docs/readme/02-oauth-setup.png)

Откройте созданное приложение на сайте. Скопируйте **ID приложения** в поле
**Client ID**, а его секретный ключ (**Client Secret**, на сайте может называться
**Ключ API**) — в **Client Secret**. Это данные вашего OAuth-приложения,
не ссылка на страницу донатов. Каждый пользователь создаёт своё приложение;
значения на скриншотах приведены только для примера.

Нажмите **Подключить аккаунт** и разрешите доступ в браузере. Поле **Код аккаунта**
можно оставить пустым. Никому не передавайте Client Secret.

![Поля Client ID и Client Secret и кнопка подключения](docs/readme/03-connect-account.png)

## Подключение DonateX

В **Настройки → Интеграция → DonateX** нажмите **Открыть кабинет DonateX**.
В кабинете откройте **Настройки → API**, скопируйте внешний токен, вставьте его
в поле программы и нажмите **Подключить DonateX**. OAuth-приложение, Client ID
и Client Secret для одного стримера не нужны.

Оставьте включённой **Защиту DonateX API**: она соблюдает официальные лимиты
REST API и не задерживает живые события SignalR. Токен хранится для текущего
пользователя Windows в зашифрованном DPAPI-хранилище и не попадает в экспорт.
Подробная инструкция: [подключение DonateX](docs/DONATEX_SETUP_RU.md).

DonationAlerts и DonateX работают независимо и могут быть подключены
одновременно. События из обоих источников проходят одинаковые правила сумм,
попадают в общую очередь и выполняются в порядке поступления.

## Каталог игры

Запустите Anomaly и обязательно загрузите сохранение. В программе нажмите **↻**
рядом со статусом игры. Затем вернитесь в игру и снимите паузу: можно просто
постоять или побегать, пока закончится сканирование. При наличии второго
монитора вынесите туда окно программы, чтобы видеть прогресс.

![Кнопка обновления каталога игры](docs/readme/04-refresh-catalog.png)

Сканирование нужно при первом подключении и после изменения сборки или модов,
которые добавляют либо меняют игровые секции. На неизменной сборке обновлять
каталог перед каждым запуском не нужно.

Недоступные и небезопасные секции по умолчанию скрыты. Для диагностики их можно
показать через **Настройки → Общие настройки → Скрывать недоступные секции**:
они будут отмечены бледно-красным, но останутся заблокированными.

## Настройка эффектов

1. Во вкладке **Шаблоны** выберите эффект, нажмите **Настроить**, сохраните
   параметры и добавьте его **В пользовательский шаблон**.
2. Во вкладке **Пользовательские шаблоны** назначьте суммы кнопкой **+ Сумма**
   и нажмите **В активные**. Один шаблон можно сохранить несколько раз с
   разными параметрами и ценами.
3. Проверьте действие кнопкой **Тест** на копии сохранения.
4. Включите **Обработку донатов** в верхней части окна.

В **Настройки → Горячие клавиши** можно назначить глобальные сочетания для
включения или остановки обработки, повтора последнего доната и запуска любого
активного шаблона по его номеру. Они работают поверх игры. Быстро назначить
сочетание отдельному активному шаблону можно через его меню **⋯**.

В **Настройки → Общие настройки** можно включить **Колесо фортуны**: если за
указанное число минут не приходит донат, программа сама запускает случайный
активный шаблон. Значение `0` отключает функцию; главный переключатель обработки
донатов на неё не влияет.

Кнопка **Профили** создаёт независимые заготовки из пользовательских шаблонов и
активных вариантов с суммами. При создании профиля пользовательские шаблоны
текущего профиля можно скопировать отдельным чекбоксом. Это позволяет быстро
переключать стиль игры, не затрагивая подключения сервисов, очередь,
историю и общие настройки.

Во вкладке **Активные** компактная строка показывает все назначенные суммы и
кнопку **Настроить**. В **Пользовательских шаблонах** отображаются первые три
суммы и быстрые кнопки **Настроить**, **+ Сумма** и **В активные**.

В истории отображаются очередь и обратный отсчёт до следующего эффекта. Общая
пауза между эффектами не теряет донат: событие остаётся в очереди до запуска.
Ещё не отправленные эффекты сохраняются и после перезапуска программы.

В **Настройки → Исключения** можно запретить любую секцию из просканированного
каталога: предмет, NPC, мутанта, отряд, аномалию, локацию или группировку.
Исключённые секции убираются из выбора, блокируются в сохранённых шаблонах и не
участвуют во внутреннем случайном выборе Lua. Не найденную сканером секцию
можно внести по её точному ID кнопкой **+ Добавить вручную**. Для быстрой
блокировки выделите запись в **Истории** и нажмите **Добавить в исключения**.
Если в эффекте была одна секция, она добавится сразу; если несколько —
программа предложит список с множественным выбором.

Если в **Общих настройках** включена **Работа в системном трее**, крестик скрывает окно, а программа
продолжает работать. Открыть её, включить или остановить обработку донатов и
полностью выйти можно через значок рядом с часами.

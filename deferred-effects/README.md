# Данные регрессионных тестов

Эти файлы сохранены для проверок совместимости и исключения снятых шаблонов из поставки. Они используются `scripts/test-lua.ps1` и тестами приложения.

Проект приложения не включает их в выходную папку `effects`. Не переносите этот каталог в игру. Актуальные шаблоны находятся в `effects` и `optional-effects`.
